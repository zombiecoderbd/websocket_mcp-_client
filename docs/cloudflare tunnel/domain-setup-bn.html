ডোমেইন রেজিস্ট্রারে লগইন করুন

প্রথমে আপনার ডোমেইন রেজিস্ট্রার (যেখান থেকে zombiecoder.my.id কিনেছেন) এ লগইন করুন। সাধারণত এটি Godaddy, Namecheap, বা অন্য কোনো কোম্পানি হতে পারে।

নেমসার্ভার আপডেট করুন

ডোমেইন ম্যানেজমেন্ট সেকশনে গিয়ে নেমসার্ভার পরিবর্তন করুন:

carmelo.ns.cloudflare.com
eloise.ns.cloudflare.com

⚠️ গুরুত্বপূর্ণ: এই কাজটি করার পর DNS প্রপাগেশনের জন্য 24-48 ঘন্টা সময় লাগতে পারে।

ক্লাউডফ্লেয়ার অ্যাকাউন্ট তৈরি করুন

cloudflare.com এ গিয়ে একটি ফ্রি অ্যাকাউন্ট তৈরি করুন। আপনার ইমেইল এবং পাসওয়ার্ড দিয়ে সাইন আপ করুন।

ডোমেইন ক্লাউডফ্লেয়ারে যোগ করুন

ক্লাউডফ্লেয়ার ড্যাশবোর্ডে গিয়ে "Add a Site" অপশন নির্বাচন করুন এবং zombiecoder.my.id লিখুন।

DNS রেকর্ড চেক করুন

ক্লাউডফ্লেয়ার স্বয়ংক্রিয়ভাবে আপনার বর্তমান DNS রেকর্ডগুলো ইমপোর্ট করবে। সবকিছু সঠিকভাবে ইমপোর্ট হয়েছে কিনা চেক করুন।

ক্লাউডফ্লেয়ারের নেমসার্ভার কনফার্ম করুন

ক্লাউডফ্লেয়ার আপনাকে দুটি নেমসার্ভার দেবে। নিশ্চিত করুন যে এগুলো আপনি ডোমেইন রেজিস্ট্রারে ঠিকভাবে সেট করেছেন:

carmelo.ns.cloudflare.com
eloise.ns.cloudflare.com

DNS সেকশনে গিয়ে নিচের সাবডোমেইনগুলো যোগ করুন:

  • zombie.zombiecoder.my.id - CNAME রেকর্ড

SSL/TLS সেটিংস কনফিগার করুন

SSL/TLS সেকশনে গিয়ে মোডটি সেট করুন: Full (strict)

নিরাপত্তা সেটিংস

WAF (ওয়েব অ্যাপ্লিকেশন ফায়ারওয়াল)

সিকিউরিটি সেকশনে গিয়ে WAF এনাবল করুন। এটি আপনার ওয়েবসাইটকে ম্যালওয়্যার এবং অন্যান্য আক্রমণ থেকে সুরক্ষিত রাখবে।

রেট লিমিটিং

সিকিউরিটি → Rate Limiting এ গিয়ে রেট লিমিট সেট করুন। এটি একই সময়ে অতিরিক্ত রিকোয়েস্ট থেকে আপনার সাইটকে রক্ষা করবে।
