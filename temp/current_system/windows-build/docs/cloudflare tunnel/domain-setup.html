Cloudflare Tunnel Domain Setup

Why Use Cloudflare Tunnel?

Cloudflare Tunnel provides secure, encrypted connections between your origin servers and Cloudflare's global network without exposing your server IP addresses. Key benefits include:

  • Enhanced Security: Hides your origin server IP address, preventing direct attacks
  • End-to-End Encryption: All traffic between your server and Cloudflare is encrypted
  • Improved Reliability: Provides a stable connection even with changing IP addresses
  • Global Performance: Leverages Cloudflare's worldwide infrastructure for faster response times
  • Granular Access Control: Allows fine-grained control over who can access your applications

How Cloudflare Tunnel Works

Cloudflare Tunnel creates a persistent, secure connection from your origin server to Cloudflare's edge network. Instead of configuring firewalls or opening ports, the tunnel connects outbound to Cloudflare, establishing a secure channel through which HTTP requests are forwarded to your applications. This means your servers don't need to be publicly accessible, reducing your attack surface.

Step 2: Cloudflare Dashboard Setup

  1. Log in to your Cloudflare account
  2. Add the domain zombiecoder.my.id
  3. Verify DNS records are imported correctly
  4. Change the domain's DNS resolution to Cloudflare

Step 3: Cloudflared Installation

  1. Install cloudflared on your origin server
  2. Authenticate cloudflared with your Cloudflare account
  3. Create a tunnel for your domain

Step 4: Subdomain Configuration

Configure DNS records for subdomains:

  • Create CNAME records for each subdomain pointing to your Cloudflare tunnel
  • Ensure SSL/TLS is set to "Full" or "Full (strict)"

Step 5: Service Routing

Configure routing for each subdomain to point to the correct services:

  • app.zombiecoder.my.id → Application server
  • zombie.zombiecoder.my.id → Zombie service server

Detailed Configuration Steps

Installing Cloudflared

# Download and install cloudflared
wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
sudo dpkg -i cloudflared-linux-amd64.deb

Creating a Tunnel

# Authenticate cloudflared
cloudflared tunnel login

# Create a tunnel
cloudflared tunnel create zombiecoder-tunnel

# Configure the tunnel to route traffic
cloudflared tunnel route dns zombiecoder-tunnel zombiecoder.my.id

Configuring Subdomains

# Route subdomains to your origin server
cloudflared tunnel route dns zombiecoder-tunnel app.zombiecoder.my.id
cloudflared tunnel route dns zombiecoder-tunnel zombie.zombiecoder.my.id

Running the Tunnel

# Run the tunnel as a service
sudo cloudflared --config /etc/cloudflared/config.yml tunnel run zombiecoder-tunnel

Important Notes

  • Ensure your origin server is accessible from the tunnel
  • Configure SSL/TLS settings appropriately in Cloudflare dashboard
  • Monitor tunnel health and connectivity regularly
  • Consider setting up health checks for your origin servers

Security Considerations

  • Use "Full (strict)" SSL/TLS mode when origin server has a valid certificate
  • Enable WAF (Web Application Firewall) rules in Cloudflare
  • Consider rate limiting to prevent abuse
  • Regularly rotate tunnel credentials

Troubleshooting

  • If DNS propagation takes too long, check TTL values
  • Verify tunnel status using cloudflared tunnel list
  • Check tunnel logs with cloudflared tunnel info [tunnel-name]
  • Test connectivity using ping or curl commands
