🧬 Z-Evo সিস্টেম ডকুমেন্টেশন

প্রফেশনাল মডুলার এআই এজেন্ট প্ল্যাটফর্ম

প্রজেক্ট ওভারভিউ

Z-Evo হল একটি প্রফেশনাল এআই এজেন্ট সিস্টেম যা ইন্ডাস্ট্রি স্ট্যান্ডার্ড আর্কিটেকচার অনুসরণ করে মডুলার মনোরিপো প্যাটার্ন ব্যবহার করে তৈরি। সিস্টেমটি সর্বোচ্চ রক্ষণাবেক্ষণ ও স্কেলেবিলিটির জন্য আলাদা আলাদা ভালোভাবে সংজ্ঞায়িত মডিউলে সংগঠিত।

কোর প্যাকেজ সমূহ সম্পন্ন

১. MCP সার্ভার (packages/mcp-server/)

উদ্দেশ্য: মডেল কোঅর্ডিনেশন প্রোটোকল বাস্তবায়ন

প্রধান কম্পোনেন্ট:

  • Server.js - মূল সার্ভার এন্ট্রি পয়েন্ট
  • ZombieCoderMCP.js - MCP প্রোটোকল হ্যান্ডলার
  • WebSocketServer.js - ওয়েবসকেট কমিউনিকেশন
  • AgentRuntimeMonitor.js - এজেন্ট মনিটরিং
  • EditorConnectionManager.js - এডিটর ইন্টিগ্রেশন

নির্ভরতা: ws, sqlite3

পোর্ট: 3002 (ওয়েবসকেট), 3003 (HTTP)

২. LSP-DAP (packages/lsp-dap/) বাকি আছে

উদ্দেশ্য: ল্যাঙ্গুয়েজ সার্ভার প্রোটোকল এবং ডিবাগ অ্যাডাপ্টার প্রোটোকল

বৈশিষ্ট্য: কোড কমপ্লিশন, ইন্টেলিসেন্স, ডিবাগিং সাপোর্ট

৩. প্রক্সি এক্সটেনশন (packages/proxy-extension/) বাকি আছে

উদ্দেশ্য: এক্সটেনশন এবং প্রক্সি ম্যানেজমেন্ট

শুরু করার পদ্ধতি সম্পন্ন

প্রয়োজনীয়তা

  • Node.js 18+
  • npm 8+

ইনস্টলেশন

# প্রজেক্ট রুটে নেভিগেট করুন cd /home/sahon/Desktop/sahon/z-evo # সমস্ত নির্ভরতা ইনস্টল করুন npm run setup # সিস্টেম শুরু করুন ./bin/launch.sh start # সিস্টেম স্ট্যাটাস চেক করুন ./bin/launch.sh status # সিস্টেম বন্ধ করুন ./bin/launch.sh stop

  • রোল-ভিত্তিক অ্যাক্সেস কন্ট্রোল

  • সিকিউর ওয়েবসকেট কানেকশন
  • এনভায়রনমেন্ট-ভিত্তিক কনফিগারেশন

ট্রাবলশুটিং সম্পন্ন

সাধারণ সমস্যা

  • পোর্ট কনফ্লিক্ট: netstat -tlnp | grep :3002
  • নির্ভরতা সমস্যা: rm -rf node_modules package-lock.json && npm run setup
  • ডেটাবেস কানেকশন: ls -la data/databases/

    • লগ ফাইল

    • সিস্টেম লগ: data/logs/
    • সার্ভার লগ: packages/mcp-server/*.log
    • এরর লগ: কনসোল আউটপুট চেক করুন

    প্রজেক্ট স্ট্যাটাস

    মডিউল অবস্থা বর্ণনা
    MCP সার্ভার সম্পন্ন মডেল কোঅর্ডিনেশন প্রোটোকল বাস্তবায়ন
    প্রজেক্ট গঠন সম্পন্ন মডুলার মনোরিপো গঠন
    লঞ্চার স্ক্রিপ্ট সম্পন্ন বিন ফোল্ডারে সিস্টেম লঞ্চার
    ডকুমেন্টেশন সম্পন্ন বাংলা ও ইংরেজি ডকুমেন্টেশন
    টেস্ট ফ্রেমওয়ার্ক সম্পন্ন ইউনিট টেস্ট এবং ইন্টিগ্রেশন টেস্ট
    LSP-DAP মডিউল বাকি আছে ল্যাঙ্গুয়েজ সার্ভার প্রোটোকল
    এপিআই গেটওয়ে বাকি আছে সেন্ট্রাল এপিআই রাউটিং
    অথেন্টিকেশন সার্ভিস বাকি আছে ইউজার অথেন্টিকেশন এবং JWT

    অবদান রাখা

    1. মডুলার গঠন অনুসরণ করুন
    2. নতুন ফিচারের জন্য টেস্ট লিখুন
    3. ডকুমেন্টেশন আপডেট করুন
    4. কোডিং স্ট্যান্ডার্ড অনুসরণ করুন
