Phase 2: System Architecture and API Design

Planned

"No-Auth" Approach

  • No traditional authentication or JWT required
  • Only OLLaMA and Open Standard Response recognition
  • Agent stability as primary security measure

Agent Tooling and Memory

  • Session Memory - Short-term conversation context
  • Context Memory - Project-level information
  • Long-term Memory - Stored in vector database
Core Focus: API Gateway, Central API Routing, and Authentication Service are missing but not needed.
"আমাদের এই সিস্টেমে কোন অথেন্টিকেশন লাগবে না এটা আমার ব্যক্তিগত ব্যবহারের জন্য শুধুমাত্র লক্ষ্য রাখতে হবে যে কোন এডিটরে যে কোন পরিস্থিতিতে যেন আপনারা এজেন্ট যাতে পাগলামি শুরু না করে"

Phase 3: Editor Extension (User Interface)

Planned

Trust Restoration

  • Absolutely plain design - no intrusive elements
  • Only connect editor to local server/agent system
  • All project features correctly integrated

Local-First Manifesto

  • Server Running + Extension Installed = Seamless Operation
  • All "magic" processing happens locally
  • Plan to escape cloud dependency

Operational Guarantee:

When server is running and extension is installed, user should never worry about connection issues, configuration, or feature integration.

"এজেন্টের পার্সনা এবং এজেন্টের ব্যবহার সহ বিভিন্ন ধরনের ঝামেলায় পড়েছি... আমার সিস্টেম কাজ করলেও আমি এডিটরে বসে কাজ করতে পারতাম না"
