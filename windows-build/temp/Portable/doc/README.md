# জম্বিকোডার এজেন্ট সিস্টেম - ডকুমেন্টেশন

## 🎯 সিস্টেমের উদ্দেশ্য
এই প্রজেক্টটি উদ্দিষ্ট হচ্ছে একটি উন্নত, বহনযোগ্য এবং উচ্চ-ক্ষমতাসম্পন্ন এজেন্ট সিস্টেম তৈরি করা যা ইন্ডাস্ট্রির সেরা প্র্যাকটিস অনুসরণ করে।

## 🏗️ আর্কিটেকচার ডায়াগ্রাম

```
[ফ্রন্টএন্ড UI] ←→ [ব্যাকএন্ড API] ←→ [MCP সার্ভার] ←→ [WebSocket]
     (3001)            (8000)            (3002/3003)      (8080)
       │                  │                   │              │
       └──────────────────┼───────────────────┼──────────────┘
                          │                   │
                    [ডেটাবেস]         [এজেন্ট ম্যানেজার]
                     (SQLite)           (LangChain/CrewAI)
```

## 🚀 সিস্টেম স্টার্টআপ

### প্রয়োজনীয়তা:
- Node.js 18+
- npm বা yarn
- লোকাল ডেভেলপমেন্ট এনভায়রনমেন্ট

### কমান্ড:
```bash
cd /home/sahon/admin/temp/Portable
node zombiecoder-complete-startup.js
```

### স্বয়ংক্রিয় কাজ:
1. **পোর্ট ক্লিনিং** - সকল প্রয়োজনীয় পোর্ট মুক্ত করা
2. **সার্ভিস শুরু** - সঠিক সিকোয়েন্সে সকল সার্ভিস শুরু করা
3. **ভেরিফিকেশন** - সার্ভিসের স্ট্যাটাস চেক করা
4. **ব্রাউজার ওপেন** - সকল ইন্টারফেস স্বয়ংক্রিয়ভাবে ওপেন করা

## 📊 সার্ভিস পোর্ট ম্যাপিং

| সার্ভিস | পোর্ট | বর্ণনা |
|---------|-------|--------|
| ফ্রন্টএন্ড | 3001 | Next.js অ্যাডমিন প্যানেল |
| ব্যাকএন্ড | 8000 | Express API সার্ভার |
| MCP অ্যাডমিন | 3002 | এজেন্ট ম্যানেজমেন্ট API |
| WebSocket | 3003 | এডিটর কানেকশন |
| WebSocket MCP | 8080 | রিয়েল-টাইম কমিউনিকেশন |

## 🔧 টেকনিক্যাল স্পেসিফিকেশন

### কোর টেকনোলজি:
- **ফ্রন্টএন্ড**: Next.js, React
- **ব্যাকএন্ড**: Node.js, Express
- **ডেটাবেস**: SQLite
- **WebSocket**: ws লাইব্রেরি
- **AI ফ্রেমওয়ার্ক**: LangChain, CrewAI
- **LLM**: Ollama (লোকাল মডেল)

### সিকিউরিটি ফিচার:
- ✅ লোকাল-সেফ আর্কিটেকচার
- ✅ কোনো এক্সটার্নাল এক্সপোজার নেই
- ✅ সিকিউর ওয়েবসকেট কমিউনিকেশন
- ✅ ভ্যালিডেশন এবং স্যানিটাইজেশন

## 🤖 এজেন্ট ম্যানেজমেন্ট

### পার্সোনা সিস্টেম:
- **টেমপ্লেট ভিত্তিক**: রিইউজেবল পার্সোনা টেমপ্লেট
- **ডাইনামিক লোডিং**: সেশন ভিত্তিক পার্সোনা লোড

- **প্রজেক্ট কনফিগারেশন**: প্রজেক্ট-ভিত্তিক সেটিংস

### বিশ্বস্ততা নীতি:
- ✅ কখনো মিথ্যা বলবে না
- ✅ "ভাইয়া আমি জানি না" - অজানা তথ্যের জন্য
- ✅ সকল উত্তরে "ভাইয়া" প্রিফিক্স
- ✅ রেফারেন্স ছাড়া কোনো দাবি করবে না

## 📈 প্রোডাক্টিভিটি ফিচার

### কোড ইন্ডেক্সিং:
- **অটোমেটিক**: নতুন ডিরেক্টরিতে কোড স্বয়ংক্রিয়ভাবে ইন্ডেক্স
- **বেস্ট প্র্যাকটিস**: ইন্ডাস্ট্রি স্ট্যান্ডার্ড অনুসরণ
- **LSP-DAP**: Language Server Protocol এবং Debug Adapter Protocol

### রিয়েল-টাইম কমিউনিকেশন:
- **WebSocket**: ইনস্ট্যান্ট মেসেজিং
- **প্রগ্রেস ট্র্যাকিং**: স্টেপ-বাই-স্টেপ আপডেট
- **এজেন্ট মনিটরিং**: লাইভ পারফরম্যান্স মেট্রিক্স

## 🛠️ ডেভেলপমেন্ট গাইড

### নতুন এজেন্ট যুক্ত করা:
1. `/mcp-server/zombiecoder-mcp-server/src/agents/` ডিরেক্টরিতে নতুন ফাইল তৈরি
2. টেমপ্লেট ফরম্যাট অনুসরণ
3. পার্সোনা কনফিগারেশন সেট করা
4. অ্যাডমিন প্যানেল থেকে টেস্ট করা

### কাস্টমাইজেশন:
- **রেসপন্স প্যাটার্ন**: অ্যাডমিন প্যানেল থেকে মডিফাই
- **মডেল কনফিগারেশন**: Ollama মডেল সেটিংস
- **টুল ইন্টিগ্রেশন**: নতুন টুল যুক্ত করা
