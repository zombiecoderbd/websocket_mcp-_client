# ইউএএস সিস্টেম ইন্টিগ্রেশন - বাংলা ব্যাখ্যা

## 🌐 সিস্টেম কিভাবে কাজ করে

### ১. প্রক্সি সার্ভার সংযোগ (Proxy Server Connection)

**লোকাল সংযোগ:**
- **Frontend (Admin Panel):** http://localhost:3001
- **Backend API Server:** http://localhost:8000
- **Cloudflare Tunnel:** সক্রিয় অবস্থায় আছে (4টি কানেকশন)

**পাবলিক অ্যাক্সেস:**
- **Admin Panel:** zombiecoder.my.id
- **API Endpoints:** app.zombiecoder.my.id
- **Direct Backend:** zombie.zombiecoder.my.id

### ২. এজেন্ট সিস্টেম (Agent System)

**বর্তমান অবস্থা:**
- ৫টি এজেন্ট সক্রিয়
- প্রতিটি এজেন্টের নিজস্ব ক্ষমতা আছে
- রিয়েল-টাইম মনিটরিং সক্রিয়

**এজেন্টের কাজ:**
- ডেটা প্রসেসিং
- অটোমেটেড টাস্ক সম্পাদন
- মেমরি ম্যানেজমেন্ট
- এডিটর ইন্টিগ্রেশন

### ৩. ওলামা মডেল সংযোগ (Ollama Model Integration)

**সংযোগ পদ্ধতি:**
- ডকার কন্টেইনারের মাধ্যমে
- `docker exec ollama ollama list` কমান্ড দিয়ে
- প্রক্সি সার্ভারের মাধ্যমে এপিআই কল

**বর্তমান অবস্থা:**
- মডেলগুলো লোড হয়েছে
- টেস্টিং ক্ষমতা সক্রিয়
- পারফরমেন্স মনিটরিং চলছে

### ৪. এডিটর ইন্টিগ্রেশন (Editor Integration)

**সংযোগ পদ্ধতি:**
- এডিটর থেকে কন্টেন্ট পাঠানো হয়
- `/api/proxy/editor/send` এপিআই এন্ডপয়েন্টে
- এজেন্টের মাধ্যমে প্রসেস হয়

**লোড হওয়া তথ্য:**
- **পার্সোনাল ডাটা:** এজেন্টের কনফিগারেশন
- **মেটা ডাটা:** কন্টেন্টের বিবরণ
- **কন্টেক্সট ইনফো:** প্রসেসিং ইতিহাস

### ৫. ক্লাউড টানেল কনফিগারেশন (Cloudflare Tunnel Configuration)

**সম্পূর্ণ কনফিগারেশন:**
```yaml
tunnel: 6ec068de-d21e-4e82-a446-e02ed28f8569
credentials-file: /home/sahon/.cloudflared/6ec068de-d21e-4e82-a446-e02ed28f8569.json

ingress:
  - hostname: zombiecoder.my.id
    service: http://localhost:3001
  - hostname: app.zombiecoder.my.id
    service: http://localhost:8000
  - hostname: zombie.zombiecoder.my.id
    service: http://localhost:8000
  - service: http_status:404
```

**অবস্থা:**
- ✅ টানেল সক্রিয় (4 কানেকশন)
- ✅ ডোমেইন রাউটিং সঠিক
- ✅ পাবলিক অ্যাক্সেস উপলব্ধ

### ৬. সিস্টেমের টেস্টিং ক্ষমতা

**টেস্ট পদ্ধতি:**
- এজেন্টের পারফরমেন্স টেস্ট
- মডেলের রেসপন্স টাইম চেক
- এডিটর থেকে ডিরেক্ট ইন্টিগ্রেশন
- কোয়ালিটি মনিটরিং

**বর্তমান রেজাল্ট:**
- এজেন্ট: ৫টি সক্রিয়
- প্রভাইডার: ২টি কনফিগারড
- প্রক্সি: সঠিকভাবে কাজ করছে
